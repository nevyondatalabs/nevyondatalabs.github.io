1. PUBLISH THE WEBSITE THROUGH YOUR EXISTING GITHUB REPOSITORY

Unzip nevyon-website-update.zip. The files to publish are:
  index.html
  images/nevyon-preview.jpg

All in-page demo images, styles and interactions are embedded in index.html. The separate JPEG supplies the social link preview. Keep the existing CNAME file and the other repository assets, including the founder portrait.

Open https://github.com/nevyondatalabs/nevyondatalabs.github.io
On the branch used by GitHub Pages, choose Add file > Upload files. Upload the new index.html to the repository root, replacing the existing one. Drag in the included images folder, preserving the path images/nevyon-preview.jpg. Review the changes and commit them, or use a branch and merge its pull request into the Pages publishing branch. A suitable commit message is: Update Nevyon website with clinical AI and signal workflows.

Do not upload the ZIP itself, local backup HTML files, the Downloads folder or reference-analysis. README.txt, this guide and image-prompts.txt are handover notes; they are not required for hosting.

Check the repository’s Actions or Pages deployment status. Once it succeeds, open https://www.nevyondatalabs.com/ and refresh. Verify the three opening modes, preprocessing, pathology patch flow, MRI contrast and overlay sliders, report tabs, time-series controls and contact links. Also open https://www.nevyondatalabs.com/images/nevyon-preview.jpg to confirm that the share image is public.

If the old page remains visible, try a hard refresh or a private window. If the deployment fails, inspect its error before uploading again.
